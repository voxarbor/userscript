# VoxArbor UA: скрипт для браузера

Українське озвучення відео на YouTube просто в браузері. Скрипт бере переклад і озвучення із сервера VoxArbor, грає
їх поверх відео й приглушує оригінал. Працює на www.youtube.com і m.youtube.com: у Chrome, Edge, Firefox і Firefox
для Android.

Це частина проєкту [VoxArbor](https://github.com/voxarbor): озвучення готують комп'ютери спільноти з
[VoxArbor Node](https://github.com/voxarbor/node), а вже готове озвучення одразу отримує кожен глядач.

## Встановлення

1. Поставте менеджер скриптів: [Violentmonkey](https://violentmonkey.github.io/) (Chrome, Firefox, Firefox для
   Android) або Tampermonkey (див. «Менеджери скриптів» нижче).
   **Chrome, Edge та інші браузери на Chromium:** менеджер на Manifest V3 запускає скрипти лише з дозволом
   браузера. Відкрийте `chrome://extensions` → «Подробиці» менеджера й увімкніть **«Дозволити скрипти користувача»**
   (Allow User Scripts; Chrome 138+). У старіших версіях замість нього потрібен «Режим розробника» вгорі сторінки
   розширень. Без цього скрипт встановлюється, але мовчки не запускається.
2. Увійдіть або зареєструйтеся на **https://voxarbor.com/panel** (можна через Google), відкрийте сторінку
   «Скрипт» і натисніть «Встановити скрипт». Менеджер сам оновлюватиме його з цієї ж адреси.
3. Оновіть сторінку «Скрипт»: скрипт підключиться до вашого облікового запису сам і сторінка покаже
   «Скрипт підключено». Якщо скрипт уже підключено до іншого облікового запису, сторінка запитає, чи перепідключити.
   Можна й вручну: на відео YouTube клацніть правою кнопкою (на телефоні — довге натискання) на кнопці озвучення,
   натисніть **«Підключити»** на вкладці «Основні» й підтвердьте той самий код на сайті.
   Токен ніхто не копіює вручну: сайт віддає його скрипту сам, а відкликати його можна у профілі на сайті.

Без облікового запису скрипт озвучує відео, що вже готові або що сервер бере для всіх; підключення дає озвучувати
нові відео для себе.

## Що вміє

- **Готове — одразу.** Якщо відео вже хтось озвучив, ви отримуєте озвучення відразу й безкоштовно. Озвучення
  починається з того місця, де відео: фраза звучить із середини й після ввімкнення, і після перемотки, і після зміни
  голосу. Щоб не пропустити початок, готове відео може стати на паузу щонайбільше на півтори секунди («Готуємо
  озвучку…»).
- **Нове — наперед.** Озвучувати нові відео можуть ті, хто ділиться своїм вузлом зі спільнотою, кому власник вузла
  відкрив до нього доступ або кому дозволив адміністратор. Тоді фрази озвучуються наперед, поки ви дивитеся. Кому
  нове недоступне, скрипт одразу пояснює чому.
- **Пауза, поки озвучення не готове.** Типово відео стає на паузу, а не грає далі без озвучення; це можна вимкнути.
- **Гучність.** Оригінал типово приглушено весь час, поки грає озвучення, або, на вибір, лише під час фраз. Гучність
  оригіналу й озвучення налаштовуються окремо.
- **Голоси.** Вкладка «Голоси»: вибір голосу зі зразками; зеленим позначено голоси, якими відео вже озвучено, і
  перемикання на них миттєве.
- **Мовці.** Один голос на все відео, два голоси (чоловічий і жіночий) або свій голос кожному мовцю. Розпізнавання
  мовців ще неточне, тому два голоси надійніші.
- Якщо у відео вже є українська доріжка від YouTube, скрипт спершу перепитає.

Налаштування відкриваються також із меню менеджера скриптів («VoxArbor UA: налаштування»).

### Якщо озвучення мовчить або запізнюється

Скрипт веде журнал: час кожного кроку запуску, кожен запит до сервера з його тривалістю, старт кожної фрази. Журнал
живе лише в пам'яті сторінки, токена в ньому немає. Відтворіть проблему, відкрийте «Налаштування → Основні →
Діагностика», натисніть «Копіювати журнал» і додайте його до повідомлення про помилку. Щоб бачити журнал ще й у
консолі браузера, поставте там позначку або додайте `?vxdebug=1` до адреси сторінки (`?vxdebug=0` вимикає).

## Менеджери скриптів

| Менеджер | Де | Стан |
|---|---|---|
| Tampermonkey, Violentmonkey | Chrome, Edge (Manifest V3) | працює; потрібен перемикач «Дозволити скрипти користувача» (див. вище) |
| Tampermonkey, Violentmonkey | Firefox, Firefox для Android | працює; на телефоні це основний шлях (m.youtube.com) |
| Greasemonkey 4 | Firefox | запускається (через `GM.*`); субтитри зі сторінки не перевірено |
| Userscripts (iOS, Safari) | iPhone, iPad | запускається (через `GM.*`), але субтитрів зі сторінки не бачить: сервер бере їх сам |
| Kiwi, Cromite | Android | не працює (Kiwi закрито; Cromite не дає `GM_*`) |

## Що потрібно скрипту

- `GM_xmlhttpRequest`: запити до сервера VoxArbor, з якого скрипт встановлено;
- `GM_getValue` / `GM_setValue`: налаштування й токен підключення;
- `GM_openInTab`: сторінка підключення на сайті;
- `GM_setClipboard`: «Копіювати журнал»;
- `GM_registerMenuCommand`: налаштування з меню менеджера скриптів (на телефоні — довге натискання на кнопці).

Де немає `GM_*`, а є лише асинхронні `GM.getValue`, `GM.setValue`, `GM.xmlHttpRequest` (Greasemonkey 4, Userscripts
на iOS), скрипт бере їх.

Скрипт працює лише на сторінках YouTube і будує інтерфейс викликами DOM, без HTML із рядків (YouTube вимагає
Trusted Types). Те, що каже сервер (чому відео не озвучується, стан підготовки), скрипт показує лише як простий
текст: один рядок до 200 символів, без розмітки й посилань.

Субтитри для перекладу скрипт бере зі сторінки: вмикає на мить потрібну доріжку через API плеєра YouTube (кнопку CC
не натискає), бере власний запит плеєра й повертає субтитри глядача як були. Якщо субтитрів немає, скрипт однаково
надсилає серверу сторінку й короткий код причини, і сервер не чекає даремно.

Адресу сервера в скрипт підставляє сам сервер, коли віддає файл. Тому встановлюйте скрипт за посиланням вище, а не
з релізів цього репозиторію: файл із релізу не знає, до якого сервера звертатися.

## Розробка

Потрібен Node.js 18 або новіший.

```sh
npm ci                # esbuild, TypeScript, vitest, openapi-typescript, Playwright
./check.sh            # усе, що перевіряє CI: типи API, типи, лише DOM-виклики, збірка, тести
node build.mjs        # dist/voxarbor.user.js
npm run e2e           # тести в браузері (потрібен Chromium Playwright: npx playwright install chromium)
npm run e2e:docker    # те саме в образі Playwright, без браузера на хості
npm run smoke:live    # вручну: справжній YouTube (не в CI)
```

- `src/` — код на TypeScript, `src/meta.ts` — заголовок скрипта і його версія.
- `test/` — тести (vitest).
- `e2e/` — тести в браузері (Playwright): зібраний скрипт на записаних сторінках YouTube (www і m., комп'ютер і два
  телефони) і з підставним сервером, що звіряє кожен запит і відповідь із `api/script-openapi.json`. Див.
  `e2e/README.md`.
- `api/script-openapi.json` — API сервера для скрипта, яке публікує сервер VoxArbor. `npm run schema` робить із
  нього `src/api/schema.d.ts`. Нове поле в API спершу з'являється на сервері, потім тут.
- Адреса сервера в коді — `__VOXARBOR_SERVER__`: сервер підставляє її, коли віддає файл.

## Випуск

Версія записана в `src/meta.ts` (`VERSION`). Тег `vX.Y.Z` з тією самою версією запускає перевірки й збірку, а
реліз отримує файл `voxarbor.user.js`. Сервер VoxArbor бере скрипт із релізу за тегом.
