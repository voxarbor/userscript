# Пропозиція до контракту скрипта: слова від сервера

Стан: **пропозиція**, сервер її ще не реалізував. Латка до серверного golden `server/tests/golden/script_openapi.json` —
`docs/contract-proposal.diff` (`git apply --check` у репозиторії сервера проходить). Усі зміни лише **додають
необов'язкові поля**: старі скрипти їх не помічають, а цей скрипт працює і з сервером без них.

## Навіщо

Скрипт має бути легким. Пояснення для людини («чому не озвучується», «що зараз робить сервер») краще писати на сервері:
там відомо, що сталося, і текст можна змінити без нового випуску скрипта. Скрипт лише показує текст.

Правило показу (уже в скрипті, `src/core/said.ts`):

- лише як простий текст: `textContent` або `title`, ніколи `innerHTML`; розмітка й посилання не працюють;
- один рядок: керівні символи, перенесення рядків і символи зміни напрямку тексту (U+202A–U+202E, U+2066–U+2069)
  стають пробілами;
- не довше 200 символів (далі «…»);
- якщо поля немає або воно не рядок, скрипт показує власний короткий текст.

## Нові поля

| Де | Поле | Тип | Що це |
|---|---|---|---|
| `PageIn` (запит) | `subs_missing` | `no_player` \| `no_tracks` \| `no_url` \| `fetch_failed` \| null | Чому сторінка без субтитрів. Скрипт уже надсилає його (сервер 0.10 ігнорує зайве поле: pydantic `extra=ignore`). |
| `VideoOut`, `SegmentsOut` | `status_text` | string ≤ 200 \| null | Слова сервера про стан відео («Розпізнаю мову: 40 %»). Підказка кнопки замість відсотка. |
| нова схема `ErrorOut` | `detail`, `message`, `reason` | `detail` як зараз; `message`: string ≤ 200 \| null; `reason`: string ≤ 40 \| null | Тіло відмови `/v1` (401, 403, 404, 429 для `POST /v1/videos` і `GET …/segments`). `message` — для людини, `reason` — машинний код. |
| `DeviceWaitOut` | `message` | string ≤ 200 \| null | Слова про вхід («Вхід скасовано на сайті»). |

`subs_missing`:

- `no_player` — на сторінці немає плеєра цього відео (або менеджер скриптів не пускає до нього, як Userscripts на iOS);
- `no_tracks` — у відео немає жодної доріжки субтитрів (і трансляції);
- `no_url` — плеєр не зробив запиту субтитрів (з його токеном), і адреса самої доріжки нічого не дала;
- `fetch_failed` — запит плеєра був, але доріжки за ним прийшли порожні.

Сервер може писати причину в журнал (зараз: «page ignored: no captions») і не чекати 20 с: сторінка без `subs` уже
зараз відпускає очікування (`take_page` ставить подію `page_wait`), і сервер одразу йде в yt-dlp.

## Рядки скрипта: що може сказати сервер

| Рядок у скрипті | Де | Коли | Що може дати сервер |
|---|---|---|---|
| «Скрипт не підключено: натисніть «Підключити»» | `core/poller.ts` | 401 | `ErrorOut.message`, `reason: invalid_token` (наприклад «Токен відкликано в профілі: підключіть скрипт знову») |
| «Сервер озвучки зайнятий, повторю за 10 с» | `core/poller.ts` | 429 (408 від проксі лишається своїм) | `ErrorOut.message`, `reason: rate_limited` |
| «Сервер відмовив (HTTP 404)» (було «HTTP 404») | `core/poller.ts` | інші 4xx | `ErrorOut.message`: «Відео немає на сервері», «Це відео не можна озвучити»; `reason`: `video_not_found`, `unsupported_url`, … |
| «помилка обробки» | `core/poller.ts` | `status: error` без `error` | сервер завжди дає `error` |
| «37%» (підказка кнопки) | `core/poller.ts` | поки відео готується | `status_text` |
| «На сайті відмовлено», «Код застарів: натисніть «Увійти» ще раз», «Не вдалося: …» | `core/signin.ts` | вхід за кодом | `DeviceWaitOut.message` / `ErrorOut.message` |
| «Код застарів.», «Сервер відмовив.» | `core/autolink.ts` | автопідключення на «Скрипт» | те саме |

Скрипт уже читає всі ці поля, коли вони є (`ApiError.said`, `Run.statusText`), і тести це перевіряють
(`test/session.test.ts`, `test/signin.test.ts`, `test/said.test.ts`).

Лишаються в скрипті (сервер про це не знає або недоступний):

- «Сервер озвучки недоступний, повторю за 10 с» — сервер не відповідає;
- «Запуск озвучки…», «Чекаю озвучку…», «Готуємо озвучку…», «Відео не знайдено» — стани сторінки й плеєра;
- питання про українську доріжку YouTube, підписи інтерфейсу.

Можна пізніше (не в цій латці): `VideoOut.notice` замість «відео озвучено голосом «…»» з кнопкою «Озвучити моїм
голосом» — це потребує дії в інтерфейсі, тож поки лишається в скрипті.

## Що зробити на сервері

1. `app/web/v1.py`: `PageIn.subs_missing: Literal[...] | None = None`; у `take_page` писати причину в журнал.
2. `status_text` у відповіді `POST /v1/videos` і `GET …/segments` (зі стану конвеєра: завантаження, розпізнавання,
   переклад, озвучення з відсотком).
3. Обробник помилок `/v1` (і `HTTPException` 401/429 у `auth`): тіло `{detail, message, reason}`.
4. `POST /v1/device/token`: `message` поруч з `error`.
5. Перезаписати golden (`tools/script_openapi.py`), скопіювати його в `api/script-openapi.json` цього репозиторію й
   виконати `npm run schema`; локальний тип `Proposed` у `src/core/said.ts` тоді можна прибрати.
